## プロジェクト概要

『潮路の商会』は、海洋交易をテーマにしたモバイル向け経営シミュレーションゲームのMVPです。

- プレイヤーは商会を運営し、船団を使って港間で貨物を輸送する。
- 契約板から輸送契約を受注し、船に貨物を積載して航海させる。
- 航海はHEXベースの海域マップ上で進行し、船の現在位置を可視化する。
- 契約達成で報酬を得て、船団と交易網を拡大する。
- 将来的にはPWA化し、必要に応じてアプリ化も検討する。

### 船の設計

- 船は帆船と動力船に分類する。
- 帆船は風などの外力により速度が変動する。
- 帆船の標準巡航速度は6ノット。
- 動力船は低速・標準・高速など、エンジン出力による速度段階を選択できる。
- 初期所有船は帆船。
- 船詳細には最大速力、常用速力、機関種類、機関出力、積載力を表示する。

### 時間の設計

- アプリ内時計・カレンダーは実時間と1:1で同期。
- 航海・荷役などの運航進行は6倍速。
- 到着期限は実経過時間に基づく。
- 到着期限は、受注時刻から「積込時間＋航海時間」の1.5倍後とする。
- 航海残り時間・到着予定・揚荷完了は6倍速で計算。
- 到着時点で期限判定を確定し、揚荷中は期限カウントを停止する。
- ユーザー向け日時は `YYYY/MM/DD（Day）HH:mm:ss` で統一する。
- 所要時間は `〇〇時間〇〇分` で統一する。1時間未満は `〇〇分`。

### 天候の設計

- 各海域HEXごとに、今後7日分の天候を事前計算する。
- 天候は2実時間ごとに変化する。
- 船は通行中のHEXの現在天候に影響される。
- 航海中に天候が変わった場合は、残距離に応じて影響を再計算する。
- 天候予報の精度は現状80%に固定。
- 将来的に予報精度を可変にする。
- 嵐は現状未実装。

### 契約板の設計

- 契約板は6実時間ごとに更新する。
- 更新時刻は00:00、06:00、12:00、18:00。
- 各港に3件、合計9件の契約を表示する。
- 各港の構成は、固定初期契約1件＋ランダム契約2件。
- 同一港内の3契約間では、貨物IDを重複させない。
- 同一港内でも、同じ出発港→到着港の航路重複は許可する。
- 受注済み契約は更新対象から除外する。
- 契約は次回更新時刻まで有効。
- 契約生成は、日付・時間帯・プレイヤーID・港IDから決定的に生成する。
- オフライン復帰後も同じ契約を再現できる。
- 各6時間区間で、手動更新を1回だけ実行できる。
- 手動更新後は、次の自動更新までボタンを無効化する。

### 契約の生成方針

- シード値は乱数を保存せず、次の要素から再現する。

```text
seed = hash(日付 + 時間帯 + プレイヤーID + 港ID)
```

- 固定初期契約は、港ごとに常に同じ貨物・航路・報酬とする。
- ランダム契約の貨物は、港ごとの輸出品から選ぶ。
- 報酬のランダム幅は、初期は±10%程度とする。
