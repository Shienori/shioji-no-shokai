# HANDOFF

## 契約詳細フルスクリーン化

- 契約詳細をボトムシート型モーダルからフルスクリーン画面へ変更
- 契約板と同じ420px幅・16px余白・カード幅100%を維持
- 戻るボタンで契約板へ戻れるように変更
- 受注・断るボタンを画面下部へ固定

## 受注後の仕様変更

- 受注後も契約板に留まる
- 受注後にFleetへ自動遷移しない
- 契約板上部に進行中契約カードを表示
- 受注済み契約は利用可能契約から除外
- ページ幅・カード密度の急激な変化を防ぐ

## Fleet画面

- 船・航海状況の確認用画面として維持
- 航路マップとプログレスバーを表示
- デバッグ情報は折りたたみ

## UI復旧

- globals.cssをUI復元基準の完全版へ戻す
- 受注後契約板用スタイルを末尾へ統合
